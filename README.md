# QWLEY-SHADE-OVERLAY

Оверлей (Dear ImGui + DirectX 11) для Roblox / ReShade.

## Редизайн окна управления
Окно «QWLEY · Overlay Control» переработано:
- **Скруглённые углы** окна, кнопок, полей и ползунков (WindowRounding 12px).
- **Чёрно-синяя тема** — тёмно-синий фон, синие акценты, голубой текст и галочки.
- **Красивый шрифт** — округлый VarelaRound (грузится из `VarelaRound-Regular.ttf` рядом с `.exe`).
- **Удобная вёрстка** — секции (SYSTEM STATUS / DISPLAY / KEYBINDS / HOTKEYS) с синими акцентами, подсказка по хоткеям, выделенная кнопка выхода.

## Шрифт
Файл `external/fonts/VarelaRound-Regular.ttf` копируется в папку сборки автоматически
(Post-build event в `Overlay.vcxproj`, Debug и Release). Если запускаете `.exe` вручную —
положите `VarelaRound-Regular.ttf` рядом с ним. Если шрифт не найден, оверлей
автоматически использует встроенный шрифт ImGui.

## Управление
- `Shift+Tab` — открыть/закрыть меню
- `F8` — ввод ReShade
- `[клавиша On/Off]` — вкл/выкл оверлея (по умолчанию `F1`, меняется в меню)
- `F2` — инверсия глубины
- `F11` — синхронизация при переходе в полный экран
- `END` — выход
